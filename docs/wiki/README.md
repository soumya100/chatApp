## Documentation rules

- Source code and checked-in configuration are authoritative.
- Never commit secrets, production URLs containing credentials, or user data.
- Update the relevant page whenever routes, environment variables, data models or workflows change.
- Treat route schemas as authoritative for exact request and response payloads.
